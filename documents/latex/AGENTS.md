# DTAK documents (LaTeX template)

A LaTeX class for printable DTAK documents: A4, two-sided, with the UPC and DTAK marks in the header. One class, `dtakdoc.cls`, holds all the styling; the document type (article or exam) is a class option, so switching type does not change the look. Everything else is plain LaTeX: packages, math, figures, bibliographies and `exam.cls` features all work as usual.

## Commands
- `latexmk`: builds `article.tex` and `exam.tex` with LuaLaTeX, writing the PDFs to `pdf/` and auxiliary files to `build/` (see `latexmkrc`). `latexmk article.tex` builds one; `latexmk -pvc` rebuilds on every save.
- pdfLaTeX and XeLaTeX work too (`latexmk -pdf`, `latexmk -xelatex`) and give the same result.
- Requirements: a standard TeX Live, MiKTeX or Overleaf install (packages `montserrat`, `exam`, `kvoptions`, `geometry`, `booktabs`, `colortbl`, `hyperref`). Nothing needs to be installed in the system.

## Files
- `dtakdoc.cls`: all the styling. Do not restyle per document.
- `article.tex`: the example article (title, abstract, sections, table, equation). Copy it and replace the content.
- `exam.tex`: the example exam (course, duration, name/ID lines, grade table, questions with points and solutions).
- `logos/`: the header marks, both **symlinks**. Do not edit, recolor or replace them.
  - `upc-barcelonatech.pdf` → `../../../slides/latex/logos/upc-barcelonatech.pdf` (the UPC mark, converted 1:1 from the official SVG).
  - `dtak.pdf` → `../../../logo/pdf/dtak_long.pdf`, generated by `tools/make_logo.py`. Regenerating the logo therefore updates the documents.
- **Using the template outside this repo** (e.g. Overleaf, or another project): copy the folder with symlinks dereferenced, so the logos become real files: `cp -rL documents/latex my-doc`, or `zip -r` (zip follows symlinks by default). Keep `dtakdoc.cls` and `logos/` next to your `.tex`, or point to them with `\documentclass[logodir=path/to/logos/]{dtakdoc}`.

## Document types
```latex
\documentclass{dtakdoc}                    % article (default; = [article])
\documentclass[exam]{dtakdoc}              % exam, on top of exam.cls
\documentclass[exam,answers]{dtakdoc}      % exam with the solutions printed (shaded in a light accent tint)
```
- Any other option (`11pt`, `12pt`, `addpoints`, `draft`, …) goes to the base class. `a4paper` and `twoside` are always on.
- Title fields, the same in both types; empty ones are skipped:
  ```latex
  \course{Course · Degree}   % small, in the accent, above the title
  \title{Title}              % Montserrat Bold, navy
  \subtitle{Subtitle}        % in the accent, below the title
  \author{Name} \date{...} \duration{2 hours}   % one muted line: author · date · duration
  \maketitle                 % exam: also adds the Name / ID lines
  ```
- `questions`, `parts`, `\gradetable`, `solution`, `checkboxes` etc. exist only with `exam` (see the `exam` package docs). Everything else in a document body works with both types.

## Identity (fixed)
- **Page:** A4, two-sided. Margins 25 mm inner and outer; the text starts 38 mm from the top.
- **Header** (added by the class; do not add logos by hand):
  - **page 1:** UPC mark left, DTAK logo right, both 10 mm tall (equal footing, as the UPC identity manual requires);
  - **even (left) pages:** UPC mark at the outer (left) edge;
  - **odd (right) pages:** DTAK logo at the outer (right) edge;
  - a thin navy rule under the logos, the full text width.
  - 10 mm is `dtak_long`'s minimum print size; the UPC mark is then 45.7 mm wide (minimum 30 mm). Do not shrink them.
- **Footer:** the page number at the outer edge (bottom right on odd pages, bottom left on even ones).
- **Fonts:** the body keeps LaTeX's default font (Latin Modern). Only the title and `\section` headings are **Montserrat Bold** in navy. `\subsection` and `\subsubsection` are the body font, bold, navy.
- **Colors** (same names as the slide templates): `dtaknavy` `#0A2A4F` (titles, header rule), `dtakaccent` UPC blue `#0076CF` (course, subtitle, links, table header rule), `dtakmuted` `#6B7785` (page numbers, author line). Use only these names, never raw hex values.
- **Tables:** booktabs; `\toprule`/`\bottomrule` in navy, `\midrule` in the accent.

## Consistency rules
1. No inline colors or fonts (`\color{red}`, `\textcolor`, `\fontfamily`, …). If something is missing, add it to `dtakdoc.cls`, using the colors above.
2. The logos appear only in the header. Do not add them to the content, and do not change the page styles per page.
3. `\maketitle` once, at the start.
4. Check the PDF before printing: odd/even headers alternate correctly and print two-sided (flip on the long edge).
