This repository is the single source of truth for the DTAK logo and slides. Every file in `logo/` is generated by `tools/make_logo.py`. Don't alter the SVGs directly.

```
dtak-image/
├── logo/                  generated: SVG (master) + png/ renders + pdf/ (vector, for LaTeX)
├── tools/make_logo.py     the logo generator (geometry, colors, fonts)
├── tools/requirements.txt
├── fonts/                 Montserrat Bold (SIL OFL, bundled) + licence
├── slides/revealjs/       slide template (see its AGENTS.md); theme/logos/dtak{,-neg}.svg are symlinks to logo/dtak_short{,_dark}.svg
└── slides/latex/          the same template for Beamer (see its AGENTS.md); logos/dtak{,-neg}.pdf are symlinks to logo/pdf/dtak_short{,_dark}.pdf
```

## The logo

It is a network icon (7 nodes, 9 edges), followed by **DTAK** and a two-line tagline:

> Data **to** knowledge
> Data **for** knowledge

| File | Content | Use |
|---|---|---|
| `dtak_long` | icon · DTAK │ tagline | main logo |
| `dtak_short` | icon · DTAK | small sizes, slide footers, next to other marks in tight spaces |
| `dtak_box` | white icon on a UPC-blue square | avatar, favicon, social media, stickers |

Each logo except `dtak_box` comes in two versions: plain for light backgrounds and `_dark` for dark ones. All SVGs have a transparent background, except `dtak_box`, which has its own blue square, and all text is converted to outlines, so they display without any fonts installed. PNG renders are in `logo/png/`: 512 px tall for long and short, 1024 px for the box. Vector PDFs, the same size as the SVGs, are in `logo/pdf/`, for LaTeX, which cannot include SVG.

### Design decisions

- **Wordmark:** "DTAK" in **Montserrat Bold** with the font's **default kerning**. The **A has no crossbar** (an open Λ) and is the only letter in the accent color: it reads as an arrow or peak, from data up to knowledge.
- **Icon:** a small graph, with data points connected into knowledge. There are three node sizes and three node colors: 3 navy, 2 UPC blue and 2 soft blue.
- **Tagline:** "Data *to* knowledge / Data *for* knowledge", set in **Helvetica Neue Roman**, the UPC corporate font. Only *to* and *for* use the accent. The two lines form three columns: "Data" and "knowledge" line up exactly on both lines, and *to* is centred over *for*. The tagline is centred vertically on DTAK's cap height, and a thin vertical divider, as tall as the cap height, separates it from DTAK.
- **Proportions,** all relative to the DTAK cap height (CAP):

  | | |
  |---|---|
  | icon height (= height of long/short) | 1.42 × CAP |
  | icon → DTAK gap | 0.35 × CAP |
  | DTAK → divider → tagline | 0.40 × CAP each |
  | tagline cap height | 0.28 × CAP |
  | tagline line spacing (baseline to baseline) | 0.474 × CAP |
  | edge and divider stroke | the same width |

- **Built to sit next to the UPC mark.** Like the UPC mark's own SVG, `dtak_long` and `dtak_short` have **no padding**, and the icon touches the top and bottom edges just as the UPC disc does. So **giving both files the same height puts them on equal footing**: the DTAK icon is exactly as tall as the UPC disc, and DTAK's cap height covers the middle 70 % of the height, the same band as the UPC descriptor text. This follows the UPC manual's coexistence rule: UPC mark on the left, the other mark on the right, no taller than the UPC symbol, and neither mark standing out.
- **On dark backgrounds the logo uses only two colors:** white (navy nodes, edges, divider, D T K, tagline) and soft blue (the blue nodes, the A, *to*/*for*).
- **The box logo is single-color:** a white icon (nodes and edges) on a UPC-blue square, with the icon at 68 % of the side.

### Usage (recommendations)

- **Clear space:** keep at least **half the logo height** free on every side. The files have no built-in margin, so leave it in the layout.
- **Minimum size:** the long logo needs at least **40 px / 10 mm** of height so the tagline stays readable. Below that, use `dtak_short`, down to 20 px / 5 mm.
- Do not recolor, stretch, re-kern or rebuild the logo from the font. Use the files.
- On photos or mid-tone backgrounds, use `dtak_box`.

## Color

| Name | HEX | RGB | Role |
|---|---|---|---|
| **UPC blue** (Pantone 2195) | `#0076CF` | 0 118 207 | accent: the A, *to*/*for*, 2 nodes, box background, slide accent |
| **Navy** | `#0A2A4F` | 10 42 79 | D T K, tagline, 3 nodes, titles, dark backgrounds |
| **Soft blue** | `#66ADE2` | 102 173 226 | UPC blue at 60 % over white: 2 nodes; replaces UPC blue on dark backgrounds |
| **Edge navy** | `#8494A7` | 132 148 167 | navy at 50 % over white (a desaturated navy): edges and divider, light version only |
| White | `#FFFFFF` | 255 255 255 | dark version and box |

UPC blue is taken from the UPC identity manual (approved CG/2026/05/12; https://www.upc.edu/comunicacio/ca/identitat/manual-identitat-corporativa-upc). Do not use other "UPC blues" found on the web (e.g. `#0A6FC7`).

The two secondary colors are **tints** (the color at a given opacity over white), so they stay in the hue of their base color: edge navy = navy at 50 %, soft blue = UPC blue at 60 %. They are set in `make_logo.py` as `EDGE_TINT` and `SOFT_TINT`.

Contrast (WCAG AA needs 4.5:1 for body text):

| Text / background | Ratio | |
|---|---|---|
| UPC blue on white | 4.67 | OK for text |
| Navy on white | 14.4 | OK |
| White on navy | 14.4 | OK |
| White on UPC blue | 4.67 | OK |
| Soft blue on navy | 5.93 | OK (AA; AAA needs 7): the accent to use on dark backgrounds |
| UPC blue on navy | 3.08 | large text and graphics only; use soft blue instead |
| Edge navy on white | 3.1 | graphics only, never text |

## Typography

| Use | Font | Notes |
|---|---|---|
| Logo wordmark (DTAK) | Montserrat Bold | outlined in the SVGs |
| Logo tagline | Helvetica Neue Roman | outlined in the SVGs |
| **First-level titles** (document and slide titles, h1/h2) | **Montserrat Bold** | matches the wordmark |
| **Everything else** (subtitles, body, tables, captions) | **Roboto** | an official UPC substitute for Helvetica Neue; fallback Arial |
| Code (`code`, `pre`) | Roboto Mono | the monospace companion of Roboto |

Montserrat, Roboto and Roboto Mono are free (SIL OFL / Apache 2.0). In the slides they come from `@fontsource/*`.

## Regenerating the logo

```sh
cd dtak-image
python3 -m venv .venv && .venv/bin/pip install -r tools/requirements.txt
.venv/bin/python -I tools/make_logo.py logo
```

- Montserrat Bold is read from `fonts/`.
- Helvetica Neue is licensed and **not bundled**. The script reads it from `~/.local/share/fonts/helvetica-neue/HelveticaNeueRoman.otf`, or from `$DTAK_TAGLINE_FONT`. It is only needed to regenerate: the SVGs already contain outlines.
- All geometry and colors are named constants at the top of `make_logo.py` (`PAL`, `NODES`, `EDGES`, `ICON_H`, `ICON_GAP`, `TAG_CAP`, …).

## Slides

`slides/revealjs/` is a reveal.js template that applies this identity. Its accent is UPC blue, titles are in Montserrat, body text is in Roboto, and section slides are navy. The footer shows the UPC mark on the left and `dtak_short` on the right. See `slides/revealjs/AGENTS.md`.

`slides/latex/` is the same template as a Beamer theme (`\usetheme{dtak}`). It has the same canvas, colors, fonts, footer and slide types, and everything else is plain Beamer. It builds with pdfLaTeX, LuaLaTeX or XeLaTeX and needs only a standard TeX distribution. See `slides/latex/AGENTS.md`.
